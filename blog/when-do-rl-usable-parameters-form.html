Research note

语言模型里，RL 真正用到的参数是什么时候形成的？

When do a language model's RL-usable parameters form?

在 SmolLM3-3B 上，RL 最终用到的那一小部分参数，在预训练早期就已经就位，远早于模型能够完成任务之前。

In SmolLM3-3B, the small set of parameters that RL ends up using is already in place early in pretraining, well before the model can do the task.

SmolLM3-3B · 14 个 checkpoint·Dr.GRPO 数学 RL，MATH-500 / GSM8K·on-policy 对角 Fisher
SmolLM3-3B · 14 checkpoints·Dr.GRPO on math, MATH-500 / GSM8K·on-policy diagonal Fisher

对语言模型做 RL，其实只改动了很少的权重。最近的工作（arXiv:2609.36262）表明：冻结大约 99% 的参数，只训练按 Fisher 信息排序的前 1%，也就是 on-policy 对角 Fisher F_i = E[(∂i log π)²]（衡量 RL 梯度能把每个权重推动多少），仍然能拿到全参数 RL 的大部分收益。

RL on a language model changes very few of its weights. Recent work (arXiv:2609.36262) shows that you can freeze about 99% of the parameters and train only the top 1% ranked by Fisher information, the on-policy diagonal F_i = E[(∂i log π)²] that measures how much the RL gradient can move each weight, and still get most of the gain from full RL.

他们证明的是：Fisher 小，期望更新就小，所以冻掉低 Fisher 的坐标损失不大。这解释了更新为什么小，也解释了为什么只训练很少的坐标就够用。它没有解释敏感度为什么稀疏：为什么大的 Fisher 只落在很少的坐标上，而不是散开。

What they prove is that a small Fisher means a small expected update, so freezing the low-Fisher coordinates costs little. That explains why the updates are small, and why training a few coordinates is enough. It does not explain why the sensitivity is sparse: why the large Fisher values sit on so few coordinates instead of spreading out.

剩下的问题在预训练：这前 1% 的位置，是模型学会推理之后才出现的，还是早就在了。

The remaining question is about pretraining: do these top-1% positions appear only after the model learns to reason, or are they already there?

结论

Summary

1. 这前 1% 的 Fisher 位置在第一阶段预训练就定下来，之后基本不再移动。到 8T token 时覆盖率已经到约 94%，比学习率开始衰减还早 2T。所以这是收敛，不是退火带来的假象。

1. The top-1% Fisher positions are set during stage 1 of pretraining and then stop moving. Coverage reaches about 94% by 8T tokens, 2T before the learning rate starts to decay. That is convergence, not an artifact of annealing.

2. 同样 0.4% 预算下，Fisher 选的位置 recover 了约 89%，而同预算的随机对照只有约 34–38%。起作用的是 Fisher 挑出的具体位置，不是预算或布局。

2. At the same 0.4% budget, the Fisher-selected positions recover about 89%, while a same-budget random control reaches only about 34–38%. What matters is the specific positions Fisher picks, not the budget or the layout.

3. 第一阶段结束时挑出的 Fisher 位置，来自一个完全做不了数学 RL 的 checkpoint。拿去训练后来那个已经会做数学的模型，recovery 是 85%，它自己挑的是 96%。位置在能力出现之前就已经标出来了。

3. The Fisher positions picked at the end of stage 1 come from a checkpoint that cannot do math RL at all. Used to train the later model that can, they recover 85%, against 96% for the positions that later model picks for itself. The positions are identified before the capability exists.

1实验设计，以及它如何绕开地板效应

1The experiment, and how it avoids the floor

直接对每个早期 checkpoint 做 RL 会撞上地板效应：模型还不会做题，RL 没有信号，也就看不出参数几何。所以把两件事拆开：位置从哪个 checkpoint 来，以及在哪个模型上训练。被训练的模型固定为 SmolLM3 做完推理中训、已经会做数学的那个 checkpoint，下文称中训模型。只变一件事：用哪个 checkpoint 的 Fisher 来挑那 1%。优化器和数据不变。

Running RL on each early checkpoint hits a floor: the model cannot do the task, so RL has no signal, and you learn nothing about the parameter geometry. Split the two questions — which checkpoint the positions come from, and which model is trained. The trained model is fixed to the SmolLM3 checkpoint after reasoning mid-training, the one that can already do math. Call it the mid-trained model. The only change is which checkpoint's Fisher picks the 1%. Same optimizer, same data.

Fisher 的测法全程相同（800 条数学题，on-policy，fp32，全局前 1%）。每次 RL 也相同（Dr.GRPO，学习率 5e-7，4×8 条 rollout，weight decay 为 0，冻结的坐标才真的不动，共 1000 步）。

Fisher is measured the same way throughout (800 math prompts, on-policy, fp32, global top 1%). Every RL run is the same (Dr.GRPO, learning rate 5e-7, 4×8 rollouts, weight decay 0 so frozen coordinates stay frozen, 1000 steps).

3只要很小一批，但必须是对的那一批

3A tiny set is enough — but it has to be the right set

先看两件事：RL 实际要动多少参数，以及换成别的位置行不行。三条线：全参数 RL（上限）、0.4% 的 Fisher 骨架、以及同预算的随机位置。

Two checks: how many parameters RL actually has to move, and whether other positions would do. Three runs: full-parameter RL (the ceiling), a 0.4% Fisher skeleton, and random positions at the same budget.

持久核心是这 0.4% 的骨架：五个里程碑（一阶段末、第二阶段、第三阶段、长上下文、中训模型）各自前 1% 的交集，也就是每一个里都进了前 1% 的坐标（12.37M，约 0.40%，主要是 GQA 里共享的 v/o 投影）。同预算随机在每个张量里保留同样的个数，只把选中的位置在张量内部打乱。

The persistent core is that 0.4% skeleton: the intersection of the top 1% at five milestones (end of stage 1, stage 2, stage 3, long context, and the mid-trained model). A coordinate has to be in the top 1% at every one of them (12.37M, about 0.40%, mostly the shared v/o projections in GQA). Same-budget random keeps the same count inside each tensor and shuffles which positions are chosen.

4这些位置很早就定了：只用第一阶段结束时挑出的位置

4Identified early: using only positions picked at the end of stage 1

起作用的是 Fisher 挑中的位置，接下来看它们什么时候出现。形成曲线说得很早，这里直接测。用第一阶段结束、还没做推理中训的那个 checkpoint 的 Fisher，看两件事：

The positions Fisher picks are what matter, so the next question is when they appear. The formation curve says early. Here we test that. Take the Fisher at the end of stage 1, before reasoning mid-training, and check two things:

(a) 一阶段末的模型自己能做数学 RL 吗？不能。全参数 RL 会塌：reward 一直贴在 0 附近（最高约 0.03），MATH-500 停在约 2.6%。没有可以强化的数学行为，这就是地板效应。

(a) Can the model at the end of stage 1 do math RL itself? No. Full-parameter RL collapses: reward stays near zero (peak about 0.03) and MATH-500 stays around 2.6%. There is no math behavior to reinforce. That is the floor.

(b) 这些位置用在中训模型上，能训起来吗？能。recovery 是 85%（MATH）和 88%（GSM），中训模型自己挑的是 96% 和 95%，全参数是上限。一阶段末标出的位置已经对了，只是那个模型自己用不了。

(b) Do those positions train the mid-trained model? Yes. Recovery is 85% on MATH and 88% on GSM, against 96% and 95% for the positions the mid-trained model picks itself, with full-parameter RL as the ceiling. The end of stage 1 already marks the right positions. That model just cannot use them.

5这说明了什么

5What this means

形成曲线、一阶段末的位置搬到中训模型上、持久核心对同预算随机，三件事说的是同一件事。RL 用到的坐标在预训练前一段就定了，后面不再搬家。之后的预训练和 RL 改变的是这些坐标上的幅度：前 1% 的 Fisher 阈值沿轨迹大约涨了 100 倍。坐标本身没变。

The formation curve, moving the end-of-stage-1 positions onto the mid-trained model, and the persistent core against same-budget random are the same fact. The coordinates RL uses are fixed in the first part of pretraining and do not move after that. Later pretraining and RL change the magnitude on those coordinates: the top-1% Fisher threshold grows about 100× along the trajectory. The coordinates do not.

所以只训练很少的 Fisher 位置仍然有效，是因为这些位置预训练时就已经在了，包括那些还做不了数学的 checkpoint。RL 没有现找一个任务子网络。

Training only a few Fisher positions still works because those positions were already there in pretraining, including in checkpoints that could not do math. RL is not finding a task subnetwork on the spot.

因此 arXiv:2609.36262 证明的是 Fisher 小则期望更新小，冻掉低 Fisher 坐标损失不大。这解释了更新为什么小，也解释了稀疏训练为什么够用。它没有解释敏感度为什么稀疏，也就是这些坐标为什么这么少、为什么是这些。那条不等式只限制每个坐标能动多远，不管它们怎么分布。这个分布是预训练里形成的，而且在第一阶段结束前就定了。

So arXiv:2609.36262 shows that a small Fisher means a small expected update, and that freezing low-Fisher coordinates costs little. That is why the updates are small, and why a sparse training set is enough. It does not say why the sensitivity is sparse: why so few coordinates, and why these. The inequality only limits how far each coordinate can move. It does not say how they are distributed. That distribution forms in pretraining, and it is already set by the end of stage 1.
